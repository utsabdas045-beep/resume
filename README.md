# Personal Portfolio Website

A modern personal portfolio website designed to showcase my work, skills, experience, and projects through a clean, editorial-style user experience.

🌐 Live Demo: https://golden-smakager-fd74c1.netlify.app/

---

## Overview

This portfolio was built to create a strong personal brand and provide visitors with a central place to learn about me, explore my projects, and get in touch.

The design focuses on:

- Modern and professional aesthetics
- Dark editorial-inspired layout
- Responsive design across devices
- Smooth user experience
- Project and skills showcase
- Personal branding through photography and storytelling

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/portfolio.git
```

Navigate to the project:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
